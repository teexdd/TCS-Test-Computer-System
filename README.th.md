# Test Computer System

[English](README.md) | **ภาษาไทย**

เครื่องมือตรวจสุขภาพคอมพิวเตอร์บน Windows เมื่อเข้าสู่ระบบ โปรแกรมจะแสดงหน้าจอเต็มสไตล์หน้าติดตั้ง ตรวจและทดสอบเครื่อง 3 ขั้นตอน บันทึกรายงานไว้ในเครื่อง แล้วพาไปหน้า Desktop พร้อมเปิดแอปที่คุณเลือกไว้ และมีหน้าต่างแอปแยกต่างหากสำหรับดูแดชบอร์ด ตั้งค่า คำเตือน และบันทึก

> **สถานะ:** เวอร์ชันเริ่มต้น คอมไพล์ผ่านแล้ว แต่ยังไม่ได้ทดสอบบนเครื่อง Windows จริงอย่างเต็มที่ ควรทดสอบก่อนแจกจ่าย

## ฟีเจอร์

### หน้าตรวจเต็มจอ 3 ขั้นตอน (แสดงตอนเข้าสู่ระบบ)
1. **กำลังตรวจ** - ข้อมูลเครื่องและตรวจว่าเป็น **PC หรือโน้ตบุ๊ก**, Driver, ประวัติเปิด-ปิดเครื่อง, แอปที่เปิดล่าสุด
2. **ทดสอบระบบ** - จอภาพ (14 ภาพสี/ลายเต็มจอ ภาพละ 0.5 วินาทีเป็นค่าเริ่มต้น), ลำโพง (ซ้าย ขวา ทั้งสองข้าง), อินเทอร์เน็ต (ping, DNS, HTTP และความเร็วดาวน์โหลดแบบเลือกได้)
3. **สรุปผล** - บันทึกรายงาน แล้วไปหน้า Desktop และเปิดแอปอัตโนมัติที่ตั้งไว้ (นับถอยหลังหรือกดปุ่ม)

- กด `Esc` หรือ **ข้ามไปหน้า Desktop** ได้ทุกเมื่อ และมีคำเตือนแสงกะพริบก่อนทดสอบจอ
- **โหมดอัตโนมัติ:** ทดสอบทุกอย่างโดยไม่ถามผู้ใช้ (ผลจอและลำโพงจะระบุว่า "ไม่ได้ยืนยัน") **โหมดโต้ตอบ:** ถามให้ยืนยันผลจอและลำโพง
- สไลด์โชว์เกร็ดความรู้ 10 ข้อ หมุนเวียน เหมือนหน้า Setup ของ Windows 11

### รายการตรวจ
| รายการ | ทำอะไร |
|---|---|
| ข้อมูลเครื่อง / ประเภท | ผู้ผลิต รุ่น CPU RAM การ์ดจอ ดิสก์ OS BIOS; แยก PC กับโน้ตบุ๊ก (chassis type, PCSystemType, แบตเตอรี่); เตือนเมื่อไดรฟ์ C: ว่างน้อยกว่า 10% |
| Driver | แสดง Driver กลุ่มสำคัญพร้อมเวอร์ชันและวันที่; หาอุปกรณ์ที่มีรหัสปัญหา (เช่น 28 = ไม่มี Driver); แจ้งเมื่อจอใช้ "Microsoft Basic Display Adapter" แบบทั่วไป |
| จอภาพ | ดำ ขาว แดง/เขียว/น้ำเงิน เทา เกรเดียนต์ แถบสี หมากรุก กริด ความคมชัดตัวอักษร ขอบจอ |
| ลำโพง | สร้างเสียงสเตอริโอ (440 / 660 / 550 Hz) ผ่าน `SoundPlayer` พร้อมไฟ L/R |
| อินเทอร์เน็ต | Adapter, ping gateway/8.8.8.8/1.1.1.1, DNS, ทดสอบ HTTP, ความเร็วดาวน์โหลด (เลือกได้) |
| ประวัติเปิด-ปิด | บูตล่าสุด uptime และเหตุการณ์ 6005/6006/6008/41/1074 ย้อนหลัง 30 วัน |
| แอปล่าสุด | หน้าต่างที่เปิดอยู่ + ประวัติ UserAssist ของ Windows (ผู้ใช้ปัจจุบัน) |

### แดชบอร์ด (หน้าต่างแอปหลัก)
- วงแหวน **คะแนนสุขภาพ** (100 - 18 ต่อรายการที่ล้มเหลว - 8 ต่อคำเตือน) ภาพ PC/โน้ตบุ๊ก การใช้ RAM และไดรฟ์ C:
- การ์ดต่อหนึ่งรายการตรวจ มีสวิตช์เปิด/ปิดและปุ่ม **Test** (ทดสอบเฉพาะรายการนั้น)
- คำเตือนล่าสุดและกราฟประวัติคะแนน
- หน้า: **หน้าหลัก**, **กิจกรรม**, **ตั้งค่า**, **คำเตือน**, **บันทึก**

### ตรวจตอนบูต (ตัวเลือก)
Task ของ Windows (รันเป็น SYSTEM หลังอนุมัติ UAC หนึ่งครั้ง) ตรวจข้อมูลเครื่อง Driver และประวัติบูตไม่กี่วินาทีหลังเปิดเครื่อง **ก่อนมีใครลงชื่อเข้าใช้** เมื่อเข้าสู่ระบบ หน้าตรวจจะแสดงผลเหล่านั้นทันทีแล้วตรวจส่วนที่เหลือต่อ Windows ไม่อนุญาตให้แอปทั่วไปแสดงหน้าจอระหว่างโลโก้บูตกับหน้าล็อกอิน หน้าจอจึงขึ้นตอนเข้าสู่ระบบ

### ตัวตรวจการเปิด-ปิดแอป (ตัวเลือก ปิดไว้เป็นค่าเริ่มต้น)
ตัวช่วยเล็ก ๆ เบื้องหลังบันทึก **เฉพาะชื่อแอปและเวลาที่เปิด/ปิด** (แอปที่มีหน้าต่าง) ไม่เก็บชื่อหน้าต่างหรือเนื้อหา ตั้งจำนวนวันที่เก็บได้และล้างประวัติได้ทุกเมื่อ

### UI 3 รูปแบบ
Windows 11 (Fluent สว่าง/มืด), Retro (เดสก์ท็อปยุค 90), Hi-Tech Terminal เลือกได้ตอนติดตั้งหรือในหน้าตั้งค่า

### ภาษา
English (US) เป็นค่าเริ่มต้น, ไทย, 简体中文, 日本語, Español เลือกตอนติดตั้ง เปลี่ยนภายหลังได้

## ความเป็นส่วนตัวและความปลอดภัย
- **ข้อมูลทั้งหมดอยู่ในเครื่อง** ไม่ส่งให้ผู้พัฒนา ไม่มีโฆษณา analytics หรือ telemetry
- เชื่อมต่อเครือข่ายเฉพาะตอนทดสอบอินเทอร์เน็ต: `www.msftconnecttest.com`, `8.8.8.8`, `1.1.1.1` และ `speed.cloudflare.com` (เฉพาะเมื่อเปิดวัดความเร็ว)
- รายการเสริมปิดไว้เป็นค่าเริ่มต้น: ซีเรียลเครื่อง ชื่อผู้ใช้ Windows ตัวตรวจแอป และ Task ตอนบูต (การวัดความเร็วปิดได้)
- ข้อกำหนดการใช้งานและประกาศความเป็นส่วนตัวแบบสากล (หลักการ GDPR/UK GDPR, CCPA/CPRA, PDPA, LGPD, PIPEDA) แสดงตอนติดตั้งและต้องยอมรับ ข้อความภาษาอังกฤษใน `lang/legal.txt` เป็นฉบับที่มีผล **เป็นเพียงแม่แบบ ไม่ใช่คำแนะนำทางกฎหมาย ควรให้ผู้เชี่ยวชาญตรวจและกรอกช่องที่เว้นไว้**
- ติดตั้งเฉพาะผู้ใช้ (`%LOCALAPPDATA%`) ไม่ต้องใช้ Admin ยกเว้น Task เริ่มก่อน/ตอนบูตที่เลือกได้ (ขอ UAC หนึ่งครั้ง) Task SYSTEM รันจากสำเนาที่ป้องกันใน `Program Files` เท่านั้น
- ไม่มี keyboard hook ไม่ฉีดโค้ด ไม่แทนที่ shell ไม่มีกลเม็ดลบตัวเอง ถอนการติดตั้งแล้วลบ Task รายการ registry และ (เลือกได้) ข้อมูลทั้งหมด

## การ build
ต้องการเพียง Windows (ใช้คอมไพเลอร์ C# ของ .NET Framework ที่มากับเครื่อง)
```
build.bat
```
ได้ไฟล์ `Test Computer System.exe` โดยฝังไฟล์ภาษาและข้อกฎหมายไว้ในตัว

## วิธีใช้
รัน exe ครั้งแรกจะเข้า **ตัวช่วยติดตั้ง** (ภาษา รูปแบบ UI รายการตรวจ การเริ่มทำงาน ข้อกำหนด ติดตั้ง) หลังติดตั้งเปิดจาก Start Menu เพื่อเข้าแอป

ตัวเลือกบรรทัดคำสั่ง:
| ตัวเลือก | ความหมาย |
|---|---|
| `/startup` | หน้าตรวจตอนเข้าสู่ระบบ (เคารพการตั้งค่า "วันละครั้ง" และโหมดอัตโนมัติ) |
| `/test` | แสดงหน้าตรวจทันที (โหมดโต้ตอบ) ใส่ `/auto` เพื่อโหมดอัตโนมัติ |
| `/only=<ชื่อ>` | ใช้กับ `/test` เพื่อทดสอบรายการเดียว (`drivers`, `display`, `speaker`, `network`, `boot`, `apps`) |
| `/monitor` | เริ่มตัวช่วยบันทึกกิจกรรมแอป |
| `/boot` | ตรวจตอนบูตแบบไม่มีหน้าจอ (ใช้โดย Task) |
| `/admin-apply ...` | ตัวช่วยสิทธิ์สูงที่สร้าง/ลบ Task |
| `/uninstall` | ถอนการติดตั้ง |

## ที่เก็บข้อมูล
| รายการ | ตำแหน่ง |
|---|---|
| โปรแกรม | `%LOCALAPPDATA%\Programs\TestComputerSystem` |
| การตั้งค่า คำเตือน ผลล่าสุด ประวัติ กิจกรรม | `%LOCALAPPDATA%\TestComputerSystem` |
| รายงาน | `C:\TestComputerSystem\Logs` (ถ้าเขียนไม่ได้จะใช้โฟลเดอร์ตั้งค่าแทน) |
| ผลตอนบูตและสำเนาที่ป้องกัน | `%ProgramFiles%\TestComputerSystem` (เฉพาะเมื่อเปิดตรวจตอนบูต) |

## โครงสร้างโปรเจกต์
```
src/            ซอร์ส C# (Program, Setup, Onboard, MainForm, Checks, Boot, Monitor, Cfg, Theme, I18n)
lang/           ไฟล์แปล *.lang + legal.txt (ฝังเข้า exe)
app.manifest    asInvoker, รองรับ DPI
app.ico         ไอคอน
build.bat       สคริปต์ build
```

## เพิ่มภาษา
1. ก๊อปปี้ `lang/en-US.lang` เป็นไฟล์ใหม่ เช่น `lang/fr-FR.lang` แล้วแปลค่า (คง `{0}` และ `\n` ไว้)
2. เพิ่มหนึ่งบรรทัดในตาราง `Langs` ของ `src/I18n.cs` (รหัส ชื่อภาษา ฟอนต์)
3. รัน `build.bat`

## ทำให้ Microsoft Defender / SmartScreen ผ่าน
ไม่มีการรับประกัน แต่ควร: เซ็น exe ด้วย code-signing certificate, ส่งไฟล์ใหม่ให้ Microsoft ตรวจ false positive (https://www.microsoft.com/wdsi/filesubmission), แจกผ่าน HTTPS พร้อม SHA-256 และไม่ใช้ packer/obfuscator ชื่อเสียงของ SmartScreen จะสะสมจากจำนวนดาวน์โหลด

## ข้อจำกัดที่ทราบ
- ทดสอบจอเฉพาะจอหลัก
- ผลจอและลำโพงยืนยันได้โดยผู้ใช้เท่านั้น โหมดอัตโนมัติจะระบุว่า "ไม่ได้ยืนยัน"
- Windows ไม่เก็บประวัติเปิดแอปครบทุกตัว ตัวตรวจกิจกรรมเห็นเฉพาะแอปที่ทำงานตอนเปิดใช้
- ตัวช่วยกิจกรรมทำงานค้างเบื้องหลังตอนเปิดใช้ (เล็ก แต่ไม่ใช่ศูนย์)
